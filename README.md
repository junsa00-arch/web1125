# 출장 여비 계산기

`index.html`을 브라우저에서 열면 바로 사용할 수 있는 오프라인 웹 앱입니다. 별도 서버, 설치, 인터넷 연결 없이 실행됩니다.

## 사용 방법

1. `index.html`을 더블 클릭해 브라우저로 엽니다. 앱은 창 너비를 채우며, 헤더의 **전체 화면** 버튼으로 브라우저 전체 화면을 켜고 끌 수 있습니다.
2. 출장일과 복귀일, 지급 구분, 숙박 지역을 선택합니다.
3. 실제 운임과 숙박비, 숙박·이동 조건을 입력합니다.
4. 오른쪽 결과에서 예상 합계와 항목별 계산을 확인합니다. **결과 인쇄 / PDF 저장** 버튼을 누르고 인쇄 대화상자에서 프린터를 선택하거나 PDF로 저장합니다. **엑셀 다운로드**를 누르면 입력 조건과 항목별 산정 내역이 담긴 `.xlsx` 파일을 저장합니다.

## 계산에 적용한 자료

- `../pdf/공무원 여비 규정(대통령령)(제36728호)(20261002).pdf`
- `../pdf/[별표 2] 국내 여비 지급표(제10조부터 제13조까지 및 제16조제1항 관련)(공무원 여비 규정).pdf`
- `../pdf/공무원여비규정_제3항부터제5항.pdf`

## 계산 전제와 한계

- 출장일과 복귀일을 모두 출장일에 포함합니다. 날짜 차이를 기본 숙박 박수로 제안하되 사용자가 수정할 수 있습니다.
- 일비와 식비는 1일 25,000원으로 계산합니다. 공무용 차량 이용 시 일비는 절반입니다.
- 제2호 숙박비는 서울 100,000원, 광역시 80,000원, 그 밖의 지역 70,000원/박 상한을 적용합니다. 제1호는 입력한 숙박 실비를 적용합니다.
- 선박·항공 여행은 원칙상 숙박비를 제외하며, 불가피한 육상 숙박 예외를 선택할 수 있습니다. 식비는 별도 지급 여부를 선택합니다.
- 제공된 자료에는 별표 1의 직급별 지급 구분이 없으므로 사용자가 제1호/제2호를 직접 선택해야 합니다.
- 철도·선박·항공·버스 운임의 등급별 제한과 자가용 사용에 대한 상세 산정 기준은 자동 판정하지 않습니다. 승인 가능한 실제 운임을 직접 입력해 주세요.
- 출장 사유·기관 내규·증빙 검토를 대신하지 않는 예상 계산입니다.
